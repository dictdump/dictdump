&F96B;4&F96C;語義･語法


4.1 語義の配列

原則として使用頻度順とした｡ただし, 必要に応じて関連性のある語義を近接して配列した場合もある｡


4.2 語義の分類

語義が多岐にわたる場合は品詞ごとに&F393;&F394;の番号を用いて区分した｡

動詞の文型には&F393;&F394;の下位区分として&F3BA;&F3BB;&F3BC;を用いた｡また形容詞などでも下位区分に&F3BA;&F3BB;&F3BC;を用いた場合がある｡また上位区分として &F38F; &F390; &F391; を用いた語もある｡


4.3 語義の要約

重要な多義語には, 本文中の語義番号を付した｢語義の要約｣を掲げた｡

例:&F151;date&F144; /deit/ &F383;&F37E;&F54C;特定の日時(に会う約束)

&F0D1;要約&F0D2;

&F383;日付&F393; 日時&F394; 時代&F395; デート&F396;

&F37E;&F372;日付を書く&F393; デートする&F396; &F371;始まる&F393;


4.4 中心義

&F150;以上の重要な多義語には, 語の意味の理解･把握を助けるため, 適宜&F54C;として語の中心的意味を示した｡


4.5 語形の指示

語形に関する特別な指示は&F0D3; &F0D4;内に次のように示した｡

&F0D3;～s&F0D4;　　　　　その語義では複数形で用いる｡

&F0D3;the ～&F0D4;　　　 その語義では定冠詞をつけて用いる｡

&F0D3;a ～&F0D4; &F0D3;an ～&F0D4; その語義では不定冠詞をつけて用いる｡

&F0D3;B- &F0D4;　　　　　見出し語は小文字だがその語義では大文字で用いる｡

&F0D3;b- &F0D4;　　　　　見出し語は大文字だがその語義では小文字で用いる｡

&F0D3;単数形で&F0D4;　　 その語義では単数形で用いる｡

また, 常に複数形で用いられ, 複数形で見出しになっている名詞は, &F381;の文字記号を用いて&F383;&F381;とした｡


4.6 用法の指示

文法･語法上の指示の主なものは次のとおり｡

&F0D3;複数扱い&F0D4;　　　　　名詞が常に複数の動詞･代名詞で受けられる｡

&F0D3;単数扱い&F0D4;　　　　　名詞が常に単数の動詞･代名詞で受けられる｡

&F0D3;単数･複数扱い&F0D4;　　 名詞が単数の動詞･代名詞, 複数の動詞･代名詞の両方で受けられる｡

&F0D3;集合的に&F0D4;　　　　　名詞が集合的に用いられる｡

&F0D3;受身形で&F0D4;　　　　　他動詞が受身形で用いられる｡

※本辞典では &F0D3;受身形で&F0D4; &F0D3;通例受身形で&F0D4; の用法指示がある場合の訳語は, 日本語として自然な表現となるようにくふうした｡

&F0D3;叙述&F0D4;　　　　　　　形容詞が動詞の補語として用いられる｡

&F0D3;限定&F0D4;　　　　　　　形容詞が名詞の前にあって直接修飾する｡

&F0D3;形容詞的に&F0D4;　　　　名詞が形容詞的に用いられる｡

&F0D3;-edで形容詞として&F0D4; 動詞が過去分詞で形容詞として用いられる｡

このほか &F0D3;進行形不可&F0D4; &F0D3;受身形不可&F0D4; &F0D3;直接話法で&F0D4; &F0D3;複合語で&F0D4; &F0D3;否定文で&F0D4; などの用法指示を用いている｡

上記の指示には必要に応じて｢通例･しばしば･ときに｣などの頻度を示す語を前置した場合がある｡


4.7 名詞の可算･不可算

名詞の可算･不可算は 可算=&F374;, 不可算=&F375; の記号で示した｡&F374;が多くの語義に共通する場合は語義番号&F393;の前に記号を挙げて代表させ, 対象外の語義には個々に&F375;または&F375;&F374;を示した｡逆の場合も同様｡

&F0D3;a ～&F0D4; &F0D3;単数形で&F0D4; &F0D3;～s&F0D4; などの語形指示がある場合は, 可算用法に含まれるものとみなして&F374;をつけてある｡&F0D3;the ～&F0D4; &F0D3;one’s ～&F0D4; の語形指示がある場合は, 常にその形で用いられるので&F375;&F374;をつけない｡


4.8 地域ラベル･時間ラベル

見出し語あるいは語義の使用される地域･時代などが限定される場合は &F0D3; &F0D4; 内に原則として略語で示した｡

&F0D3;米&F0D4; 米国用法　&F0D3;英&F0D4; 英国用法　 &F0D3;カナダ&F0D4; カナダ用法

&F0D3;豪&F0D4; オーストラリア用法　　　　&F0D3;ニュージ&F0D4; ニュージーランド用法

&F0D3;スコット&F0D4; スコットランド用法　&F0D3;北イング&F0D4; 北イングランド用法

&F0D3;アイル&F0D4; アイルランド用法　　　&F0D3;南ア&F0D4; 南アフリカ用法


4.9 スピーチラベル

スピーチラベルも同様に &F0D3; &F0D4; 内に略語で示した｡これらの略語は訳語の頭につけたほか, 用例･語法欄の解説文や(◆ ) の注記文の中でも用いている｡

&F0D3;堅&F0D4; 主に文書中や改まった場での会話･演説などで用いる｡

&F0D3;口&F0D4; 日常会話やくだけた場面での書き言葉として用いる｡

&F0D3;俗&F0D4; 非常にくだけた会話や特定の集団内などで用いる｡

&F0D3;卑&F0D4; 卑わい･下品な用法で通常は使用を避ける｡

&F0D3;文&F0D4; 主に改まった書き言葉で用いる｡

&F0D3;商標&F0D4; 商標登録された名称であることを表す｡

&F0D3;けなして&F0D4; 軽蔑的な気持ちを表す用法｡

&F0D3;蔑&F0D4; 人種差別･性差別など, 非常に強い侮蔑的･挑発的な響きを持つ表現で, 通常は用いてはならないとされる｡

&F0D3;戯&F0D4; こっけいな効果をねらった用法｡

&F0D3;婉曲的&F0D4; 直接表現するのを避けて遠まわしに別の言葉で言い換えた表現｡

&F0D3;比喩的に&F0D4; 比喩的な用法｡

&F0D3;古&F0D4; 昔は用いられたが現在は使われない用法｡

&F0D3;旧&F0D4; 現在では古臭いと感じられる用法｡

&F0D3;方&F0D4; 特定の地域で用いる用法｡

これらのラベル表示は &F0D3;米口&F0D4; &F0D3;豪俗&F0D4; &F0D3;英では古&F0D4; のように組み合わせて用いる場合もある｡

上記のうち, 特に使用に注意を要する &F0D3;卑&F0D4; &F0D3;蔑&F0D4; には&F362;印を付して注意を喚起した｡


4.10 百科記号･専門語

専門語や特定の分野で用いられる用語は &F0D5; &F0D6; 内に示した｡&F0D5;野球&F0D6; など自明なもののほか, 多くの分野について省略形を用いた(→&F96B;11&F96C; 記号一覧)｡

また, コンピューター, インターネット関連の語義については, &F0D5;コンピ&F0D6;記号を用いて示した｡


4.11 補足説明

語義には理解を助けるための補足説明をつけている場合がある｡訳語の補足は ( ), 参考的解説は訳語の後の &F973; &F974;, 語法注記(→4.19) は (◆ ), コミュニケーション情報(→4.23) は (&F38E; ) 内に示した｡


4.12 動詞の訳語

他動詞の訳語には｢…を, …の, …から｣などをつけて目的語との関係を明確にした｡目的語が特定される場合は&F96B; &F96C;内に示した｡なお, 4.3｢語義の要約｣内における訳語で, 目的語を特定しないと意味のとりにくいものについては ( ) 内に示した｡


4.13 形容詞の訳語

形容詞の被修飾語が限定される場合は ( ) 内 に示した｡


4.14 同意語･反意語･&F38B;&F38C;

同意語は訳語の後に ( ) として示した｡意味はほぼ同じだが, よりくだけた表現になる場合は&F38B;をつけて (&F38B; ) のようにした｡より改まった表現になる場合は&F38C;をつけて (&F38C; ) のようにした｡反意語･対応語は (⇔ ) とした｡


4.15 中立的表現

性差別につながる恐れがある語には, (&F54D; ) として男女一方の立場に偏しない中立的な代替表現を示した｡なお, 人種差別などに関わる語･表現には適宜 (◆ ) などの注記を付して注意を促した｡


4.16 参照語の指示

その語との関連で参照することが望ましい記述を含む見出し語を (&F38D; ) で示した｡関係のある語は (→ ) で示した｡


4.17 コロケーション

見出し語と密接に結びついて用いられる重要な前置詞などの要素は訳語の後の&F971; &F972;内に太字で示し, 原則として訳語にも対応する語句を&F971; &F972;で包んで示した｡意味上対比的な前置詞などは&F971; &F972;内に訳語を示した｡

例:&F14F;cau･tion /k&F0E4;&F0E0;&F0DD;&F0E7;n/ … &F36F;&F37E;&F372; &F393; 警告する&F3BA; &F0D3;+&F384;&F0D4;…に警告する,注意する&F971;against …しないように;about …について&F972;¶The doctor cautioned him against his jogging.&F95F;医者は彼にジョギングをしないように注意した

重要な副詞は&F973; &F974;に包んで訳語の後に斜体太字で示した｡

例:&F150;breathe /bri&F0E0;&F0DE;/ &F393; 呼吸する,息をする&F973;in, out&F974;

4.18 入れ替え

訳語のうち入れ替え可能な部分を[ ]に包んだ場合がある｡


4.19 語法

学習上重要な語法項目は&F54B;欄を設けてくわしく解説した｡

なお, 該当項目のうち, 比較的簡単な内容のものは (◆　) で適宜訳語の中で解説した｡


4.20 上記の解説文中で, ｢…とはいわない｣や誤りを含む表現には&F14E;印をつけて注意を促した｡

例:&F14F;cat･tle /k&F078;&F0BB;l/ &F383;&F375;&F0D3;集合的に&F0D4;&F0D3;複数扱い&F0D4; &F393; 牛(の群れ),畜牛…(◆cattle は｢群れ｣として考えるので,two, three といった小さな数とともには用いない.また不可算名詞なので &F14E;a cattle, &F14E;cattles は不可)

4.21 類語欄

&F54E;欄で類義語をまとめて比較解説した｡


4.22 類語パネル

語の意味の違いを図表で示し, ([類語パネル]→&F542;)として掲載したものもある｡


4.23 コミュニケーション情報

(&F38E; ) でコミュニケーション情報に関する注記を示した｡


4.24 &F548;表現

文章を組み立てる際に重要な役割を果たす単語･フレーズ･定型的な文などに&F548;の記号をつけて注意を促した｡(→&F96B;別項&F96C;NAVI表現)
