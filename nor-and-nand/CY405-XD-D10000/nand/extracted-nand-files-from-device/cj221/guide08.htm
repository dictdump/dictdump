7-1 本辞典で用いた記号類をまとめると,次のようになる.

(　　) &F15F;省略可能を示す

　&F160;訳語の異同やニュアンスの違いを示す

(→　) 中間表現.英文への日本文の発想展開部分を包む

(◆　) 注記･補足的説明を包む

(▲　) 日英比較上の注記を包む

([言い換え]　) (&F15C;　) (&F16E;　) (&F16D;　) ([日本語直訳]　)

　それぞれ各種言い換え表現を包む(4-11～14 参照)

(⇒　) 参照せよ

[　　] 前の語句との交換を示す

[or　] 前の語句と交換しても意味の変わらないことを示す

&F973;　　&F974; 語義の分類を示す

&F050;　　&F051; 言語用法を包む

&F052;　　&F053; 文型の表示を包む

&F971;　　&F972; 訳語に対して特定の結びつきのある語や目的語を包む

｢　　　言い換える場合,その部分から言い換えることを示す

¶　　 用例を示す

|　　　用例の通常の言い換えの区切りを示す

‡　　 複合語を示す

;　　　訳語間の区切りを示す (3-3 参照)
