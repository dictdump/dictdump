構成と各項目の利用法(5)

■スタイルラベル

　OALD では特定の状況などで使用される単語にラベルがついています｡ 以下にそれぞれのラベルの表す意味を解説しますので､ 単語を引く際にはぜひ活用してください｡

approving :承認や賞賛を示すときの語

disapproving :非難や軽蔑を示すときの語

figurative :文字通りではなく比喩的に使われる語

formal :改まった場面や公式の場面で使用される表現であり､ 日常会話で用いない語

humorous :通例ジョークなどを言う際に使用する語

informal :友人同士の会話などの非公式の場面で用いられる表現であり､ 公式な場面で用いるのは不適切である語

ironic :実際に言葉にしている意味とは逆の意味を意図して用いる語

literary :文学やフィクションで主に用いられる語

offensive :特に人種､ 宗教､ 性別､ 身体障害についての非常に侮辱的な語｡ 通常使用を避けるべき差別用語

slang :同じ年頃の仲間や同じ ｢活動｣ (あるいは仕事) を持った特定のグループ内だけで用いられる非常にくだけた語

taboo :厳しく禁止されていて､ 口にしてはならないと多くの人々が思うような語

technical :特定の分野で用いられる専門用語

&F16D;以下のラベルは使い方が限定される単語に付されています｡

dialect :アイルランド､ スコットランド､ ウェールズを除くブリテン諸島の地方特有の表現

old-fashioned :現在では使うと古めかしく聞こえるので用いられなくなった表現

old use :もはや使われなくなった表現

saying :コメントやアドバイスをするときなどに用いることわざなどの決まり文句や伝統的な表現

■verb patterns (動詞型)

　動詞が目的語をとる場合でも､ 名詞をとるのか､ that節をとるのか､ 不定詞をとるのかなどの文法上の特性は､ 英語を使うときには欠かせない情報です｡ OALD では次の動詞型を用いて動詞の用法を具体的に示しています｡

●自動詞

[V] :後ろに目的語を必要としない動詞

[V + adv. / prep.] :動詞 + 副詞あるいは前置詞句

●他動詞

[VN] :動詞 + 名詞句

[VN + adv. / prep.] :動詞 + 名詞句 + 副詞あるいは前置詞句

●他動詞 + 2つの目的語

[VNN] :動詞 + 名詞句 + 名詞句

●連結動詞

[V-ADJ] :動詞 + 形容詞

[V-N] :動詞 + 名詞句 (補語)

[VN-ADJ] :動詞 + 名詞句 + 形容詞

[VN-N] :動詞 + 名詞句 + 名詞句 (目的補語)

●節や句とともに使われる動詞

[V that] [V (that)] :動詞 + that節

[VN that] [VN (that)] :動詞 + 名詞句 + that節

[V wh-] :動詞 + 疑問詞節

[VN wh-] :動詞 + 名詞句 + 疑問詞節

[V to] :動詞 + to不定詞

[VN to] :動詞 + 名詞句 + to不定詞

[VN inf] :動詞 + 名詞句 + 原形不定詞

[V -ing] :動詞 + -ing形

[VN -ing] :動詞 + 名詞句 + -ing形

●動詞 + 直接話法

[V speech] :動詞 + 直接話法

[VN speech] :動詞 + 名詞句 + 直接話法
