図から検索の意味と使い方


&F979;生息環境&F97A;

魚はどこでも自由に泳ぎまわっているように見えますが､じつは自分に合った環境を選んですんでいます｡おもな5つの生息環境の意味は次のとおりです｡


砂泥底域　　= 平坦で隠れる場所も少ない厳しい環境です｡すむ魚は限られます｡

岩礁域　　　= 岩場や大きな岩石が転がる海底を意味しています｡多様な魚が見られます｡

サンゴ礁域　= 造礁サンゴがつくり上げた地形で､暖かい南の海に発達します｡色の美しい魚が数多く見られます｡

河口域･藻場 = 河口は､淡水と海水が混じり合う｢汽水｣という環境で､特有の魚が見られます｡藻場はおもに沿岸の､海藻や海草が繁茂する場所です｡河口域や藻場は動･植物プランクトンが多く､魚にとって､幼魚が育つ大切な場所なのです｡

外洋　　　　= 外洋はえさになるものが極端に少ない､非常に厳しい環境です｡ここでは､広い海を回遊する魚(回遊魚)が見られます｡



&F979;体形&F97A;

いろいろな魚の体形を､おもに断面を中心にしてグループ分けしています(用語&図説の｢魚類用語の図解｣参照)｡


マグロ･サメ形　　= 断面が円形で遊泳力が強い魚です｡

タイ･アジ･ハタ形 = 断面が横に平ら(側扁)で､一般的にイメージする魚の体形です｡

ウナギ･ヤガラ形　= 体が細長い魚です｡

ハゼ･ギンポ形　　= 体が円筒形で､特に頭が大きい魚です｡

ヒラメ･エイ形　　= 体が上下に平たい(縦扁)魚です｡

そのほか　　　　 = 以上のものに当てはまらない形のものです｡
