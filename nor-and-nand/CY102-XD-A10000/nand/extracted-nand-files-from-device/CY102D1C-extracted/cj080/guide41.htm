名詞

複数形が -s (あるいは､-s, -x, -z, -sh, 軟音の -ch で終わる場合は -es)を付けることで形成されるものは規則的と見なしこの辞書では複数形を記載していない｡

その他の場合､特に次のものについては､各複数形を示した｡

･ -i または -o で終わる名詞｡ 例:agouti → agoutis; albino → albinos

･ ラテン語に由来するかそう思われる -a, um, -us で終わる名詞｡ 例:alumna → alumnae; spectrum → spectra; alveolus → alveoli

･ -y で終わる名詞｡ 例:fly → flies

･ 複数形が2つ以上ある名詞｡ 例:storey → storeys or stories

･ 複数形が語幹の変化を示す名詞｡ 例:foot → feet

･ 複数形が単数形と同じ名詞｡ sheep → sheep


形容詞

比較級と最上級については次の語形を規則的と見なし､この辞書では､各変化形を特別に記載していない｡

･ 1音節からなる語で､ -er と -est が付く場合｡ 例:great → greater, greatest

･ 1音節からなる語で､黙音 e で終わり､その -e が落ちて -er と -est が付く場合｡ 例:brave → braver, bravest

･ ’more’ と ’most’ が付くことによって比較級と最上級を作る単語｡

その他の場合､特に次のものについては､比較級と最上級をそれぞれ示した｡

･ 最後の子音を重ねることによって比較級と最上級を作る形容詞｡ 例:hot → hotter, hottest

･ 2音節からなる語で､ -er と -est によって比較級と最上級を作る形容詞(典型的には -y で終わる形容詞とその否定形)｡ 例:happy → happier, happiest; unhappy → unhappier, unhappiest
