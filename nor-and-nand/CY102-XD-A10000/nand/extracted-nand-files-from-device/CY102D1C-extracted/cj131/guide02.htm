二､本辞典の配列方法


(1)部首による配列

親字は､部首に従って配列した｡部首立ては､&F977;康煕字典&F978;の部首に基づいたが､次の点について新しい工夫を加えた｡


&F493;部首の新設

&F2C2;部を新たに設けて､新字体のうち従来の部首では分類しがたい単･巣･営･厳などの文字を収めた｡


&F494;部首の合併

次の部首は､形が類似するので合併した｡


匚(はこがまえ)　　 と 匸(かくしがまえ)

夂(ふゆがしら)　　 と 夊(すいにょう)

彳(ぎょうにんべん) と 行(ぎょうがまえ)

日(ひ)　　　　　　 と 曰(ひらび)

月(つき)　　　　　 と 肉月(にくづき｡肉部の文字で月の形になるもの)


&F495;部首の分離

次の部首は､もとは同じ部首としてまとめられていたが､字形が異なるので分離した｡分離した部首は､もとの部首の直後に置いた｡


刀(かたな)　　　　 と &F054;(りっとう)

心(こころ)　　　　 と &F1B8;(りっしんべん)

手(て)　　　　　　 と &F1F5;(てへん)

水(みず)　　　　　 と &F3AF;(さんずい)

火(ひ)　　　　　　 と &F477;(れんが)

犬(いぬ)　　　　　 と &F4B8;(けものへん)

网(あみがしら)　　 と &F6E8;(よこめ)

肉(にく)　　　　　 と 肉月(にくづき｡肉部の文字で月の形になるもの)

衣(ころも)　　　　 と &F8A6;(ころもへん)


なお､｢おいかんむり(老･&F741;)｣｢くさかんむり(艸･&F796;)｣｢しんにょう(&EDD1;･&F989;･&F98A;)｣なども字形が著しく異なるが､これらは従来通り同一の部首として扱った｡

また､｢しめすへん(示･&F5DE;)｣､｢せい(齊･斉)｣､｢は(齒･歯)｣など､新旧字体の関係にある場合も､従来通り同一の部首として扱った｡


(2)同一部首内での親字の配列

同一部首内では､親字は､原則として部首を除いた部分の画数(部首内画数)によって配列した｡部首内画数が同じ場合には､代表的な音の五十音順によって配列した｡国字については､音が存在しないものとして､同一部首内画数の中での一番最後に置くのを原則としたが､検索の便宜上､音を仮定して配列したものもある｡同一部首内画数の国字が二文字以上ある場合は､訓の五十音順によって配列した｡

ただし､部首そのものを表す文字(玉･田など)については､音にこだわらずにその部首の冒頭に置いた｡


(3)熟語の配列

熟語の配列は､二字めの漢字の音読みの五十音順によった｡ただし､二字めの漢字が特殊な音を持つ場合には､一般的な音に従った｡
