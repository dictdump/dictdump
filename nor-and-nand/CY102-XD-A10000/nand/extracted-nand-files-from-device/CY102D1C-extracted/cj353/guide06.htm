COLLOCATION BOXES (コロケーション･ボックス)

　コロケーション(collocation,｢連語｣とも言う)は,ある単語を実際に話したり書いたりする際に,どういう単語とよく一緒に使うかに関する情報である｡コロケーションに関する情報は,LDOCEの初版,第2版ではあまり系統的に盛り込まれていなかった｡大規模コーパスからさまざまな単語の共起(一緒に使う単語)の情報が得られるようになってから,この10年あまりの間に,辞典の重要な情報として続々と学習辞典に掲載されるようになった｡

　LDOCE第4版では,このコロケーションの情報がCollocation Boxesという本格的なコラムの形に整理されて一括して掲載されることになった｡コロケーション･ボックスは,使用頻度の高い基本名詞に多く設けられている(動詞の場合には,SPOKEN PHRASESという同様のコラム形式のボックスで取り上げられている)｡例としてschoolを見てみよう｡

　schoolという名詞に対して,go to school, attend schoolといった｢動詞 + school｣のコロケーション,a new school (新しく行く学校),sb's old school (母校)のような｢形容詞 + school｣のコロケーション,さらにschool children/pupils/teacher(学校の生徒/先生),school uniform(制服),school playground/library/bus(校庭/学校図書館/スクールバス),などの｢school + 名詞｣のコロケーションが挙げられている｡

　schoolで高頻度に用いられるパターンがコーパスからデータを基に実によくまとめられている｡またこれらのコロケーションのリストの直後にはそれらを用いた例文が適宜示されているので,単にフレーズのレベルだけでなく実際に使い方がわかるように配慮されている｡

　もう1つ,possibleを見てみよう｡コロケーション･ボックスは名詞がほとんどだが,使い分けが重要な形容詞にも設けられていることがある｡

[BOX]

it is possible (for sb) to do sth

make it possible (for sb) to do sth

where/whenever/wherever possible (=every time you have an opportunity)

do everything possible

(in) every way possible

technically possible (=possible using the scientific knowledge available)


　形容詞のコロケーションの場合は,it is possible (for sb) to do sthやwhere/whenever/wherever possibleのような文や修飾節のレベルでのコロケーション,do everything possibleのような動詞句でのコロケーション,technically possibleのような副詞とのコロケーションが中心に示されている｡

　従来の英和辞典などでもコロケーションのコラムはあったが,取り扱いが中途半端なものが多く,十分に役に立つという実感があまり得られなかった｡今回のLDOCE第4版のコロケーション･ボックスはそういった意味で,語の使用についてコーパスを十分に活用した情報が整理された形で提示されており,満足できるものになっている｡

　なお,1つ注意が必要なのが,コロケーション･ボックスがたいていの場合名詞に関して提供されている,という点である｡これは名詞を中心としたコロケーションが,最もこのような整理方法に適しているからであり,｢名詞を出発点にして表現を拡張する｣という考えに基づいているからである｡確かに動詞に関しても,名詞･副詞とのコロケーションがあるが,コロケーション･ボックスは設けられていない｡これは,動詞の場合,動詞型(動詞の文型)の記述が中心になるので,コラムで先頭にまとめてしまうよりも,動詞型の各項目の下でコロケーションを出すほうが,学習者にとってわかりやすいからである｡このようにコーパスからの情報を工夫して提示している点が,今回のLDOCE第4版の使いやすさの1つの大きな特徴になっている｡

　コロケーション･ボックスを中心とした辞典中のコロケーション例は6万3000以上にのぼる｡
